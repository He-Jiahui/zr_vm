## 实现产出

- 公共 `SZrReflectionResolvedGenericMethodSpec` 保留 MethodSpec/method token 和 record、完整 signature hash、参数
  count/list offset，以及借用的 request argument view。
- 公共 `ZrCore_Reflection_ResolveConstructedGenericMethod()` 只接受 attached runtime 的本地 MethodDef，先消费
  11-S5A owner range，再按稳定的 function-record/module-record 顺序寻找既有 MethodSpec。
- 既有 TypeSpec matcher 的 argument validation 与 recursive signature-node matching 提升为 core-internal 共享入口；
  primitive、TypeDef/TypeRef/TypeSpec、array、tuple、ownership、nullable、union 继续使用单一匹配语义。
- 无匹配 MethodSpec、arity/type/order mismatch、损坏 owner、非法 argument、错误 token 或空输入全部 fail closed；
  不伪造 MethodSpec token，也不创建或缓存新 metadata entity。
